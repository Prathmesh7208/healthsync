# Phase 2 — Diagnostic Lab Integration

**Module Prefix:** `LAB`
**Priority:** P2 — Should Have (Phase 2)
**Status:** Draft

---

## 5.1 Purpose

Connects patients with accredited diagnostic laboratories to schedule home sample collection based on lab tests recommended in digital health records.

---

## 5.2 Key Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| LAB-FR-001 | System MUST extract required diagnostic tests from doctor's consultation notes/prescriptions | P1 |
| LAB-FR-002 | Patient MUST be able to compare partner lab prices and book home sample collection slots | P2 |
| LAB-FR-003 | Diagnostic labs MUST ingest test result PDFs directly into patient's HealthSync Digital Health Records | P1 |
| LAB-FR-004 | System MUST notify patient and prescribing doctor as soon as lab reports are ready | P1 |
