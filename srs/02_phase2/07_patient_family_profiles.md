# Phase 2 — Patient Family Profiles

**Module Prefix:** `FAM`
**Priority:** P1 — Must Have (Phase 2)
**Status:** Draft

---

## 7.1 Purpose

Enables a primary HealthSync user to register and manage secondary profiles for dependents (children, elderly parents) under a single account and mobile number.

---

## 7.2 Key Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| FAM-FR-001 | Primary account holder MUST be able to add up to 6 dependent family members | P1 |
| FAM-FR-002 | Each dependent MUST receive a unique sub-HealthSync ID (e.g., `HS-2026-A3K9M2-01`) | P1 |
| FAM-FR-003 | Primary user MUST be able to switch active profiles during appointment booking with one tap | P1 |
| FAM-FR-004 | Dependent medical records MUST remain isolated to that specific family profile | P1 |
