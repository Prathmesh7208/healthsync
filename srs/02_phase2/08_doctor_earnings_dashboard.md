# Phase 2 — Doctor Earnings Dashboard

**Module Prefix:** `EAR`
**Priority:** P1 — Must Have (Phase 2)
**Status:** Draft

---

## 8.1 Purpose

Provides doctors with real-time visibility into consultation revenues, completed video calls, pending payouts, platform fees, and tax summaries.

---

## 8.2 Key Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| EAR-FR-001 | Dashboard MUST display gross earnings, platform commission breakdown, and net payout | P1 |
| EAR-FR-002 | System MUST execute automated weekly payouts directly to doctor's verified bank account (via Razorpay Route) | P1 |
| EAR-FR-003 | Doctor MUST be able to export monthly financial tax statements in PDF/CSV format | P2 |
